## 📖 درباره پروژه (About the Project)

**همیار CRM** یک سیستم یکپارچه و هوشمند مدیریت ارتباط با مشتریان (Customer Relationship Management) است که با جدیدترین نسخه **Next.js 16 (App Router)**، **React 19** و **Tailwind CSS v4** طراحی و توسعه داده شده است.

این سامانه به صورت بومی از زبان فارسی و جهت‌بندی راست‌چین (**RTL**) پشتیبانی می‌کند و با استفاده از فونت استاندارد **وزیرمتن (Vazirmatn)**، رابط کاربری تمیز، چشم‌نواز و حرفه‌ای را برای تیم‌های فروش، پشتیبانی و مدیران سازمان‌ها فراهم می‌سازد.

## ✨ قابلیت‌ها و ویژگی‌های کلیدی (Key Features)

### 📊 ۱. پیشخوان مدیریتی و تحلیلی (Executive Dashboard)
- **کارت‌های شاخص کلیدی عملکرد (KPI Cards):** نمایش آمار لحظه‌ای مشتریان، تماس‌های برقرار شده، معاملات برنده و باخته، وظایف باز و جلسات با نشانگرهای نرخ رشد و افت.
- **نمودار تعاملی چرخه فروش (Sales Cycle Chart):** مقایسه روند جذب مشتریان جدید در برابر مشتریان قبلی در دوره‌های زمانی مختلف.
- **ویجت برترین شرکت‌ها (Top Companies):** رتبه‌بندی سازمان‌ها و شرکای تجاری بر اساس گردش مالی و ارزش معاملات.
- **فیلترهای زمانی پویا:** فیلتر اطلاعات بر مبنای این ماه، ۳۰ روز گذشته، فصل جاری و سالانه.

### 🎯 ۲. مدیریت قیف فروش (Sales Pipeline & Kanban)
- نمایش مراحل فروش در قالب بورد کانبان تعاملی (سرنخ جدید، تماس اولیه، جلسه و دمو، پیش‌فاکتور، مذاکره، برنده شده).
- تفکیک ارزش ریالی هر مرحله و مشاهده احتمال موفقیت معاملات.

### 👥 ۳. دایرکتوری مخاطبین و سرنخ‌ها (Contacts & Leads Directory)
- ثبت و مدیریت اشخاص، شرکت‌ها، شماره‌های تماس، ایمیل سازمانی و وضعیت فعلی مذاکرات.
- فیلتر و جستجوی لحظه‌ای در میان لیست مخاطبین.

### 📦 ۴. کاتالوگ محصولات و خدمات (Products & Services)
- مدیریت لیست محصولات، شناسه کالا (SKU)، موجودی انبار، دسته‌بندی و قیمت‌گذاری به همراه وضعیت فعال/ناموجود.

### 📅 ۵. پیگیری فعالیت‌ها و وظایف (Activities & Tasks)
- فهرست کارهای روزانه، اولویت‌بندی فعالیت‌ها (فوری، متوسط، عادی)، موعد انجام و ثبت وضعیت اتمام تسک‌ها.

### 💬 ۶. مرکز پیام‌ها و گفتگوها (Messaging Center)
- پیام‌رسان داخلی و تعامل مستقیم با مشتریان و همکاران.

### 🤖 ۷. دستیار هوشمند اختصاصی (AI Assistant Widget)
- ویجت شناور هوش مصنوعی برای پاسخ به سوالات پرکاربرد کاربران، راهنمایی گام‌به‌گام درباره نحوه استفاده از بخش‌های مختلف سامانه و پشتیبانی هوشمند.

### 🔔 ۸. سامانه اعلان‌ها و هشدارها (Notifications Center)
- اعلان‌های پاپ‌اور در هدر، شمارنده اعلان‌های خوانده نشده، امکان علامت‌گذاری به عنوان خوانده شده و پنجره مشاهده جزئیات اعلان با قابلیت هدایت مستقیم به بخش مربوطه.

### 🔍 ۹. جستجوی سراسری سریع (Command / Global Search)
- مودال جستجوی سریع با فشردن میانبر یا آیکون جستجو جهت یافتن مخاطبان، قراردادها، وظایف و بخش‌ها در کمترین زمان.

### 🔐 ۱۰. پروفایل و شبیه‌سازی ورود/ثبت‌نام (Auth & User State)
- قابلیت ثبت مشخصات کاربر و ذخیره‌سازی اطلاعات در `localStorage`، محدودسازی دسترسی به فرم‌های ثبت رکورد برای کاربران غیرمجاز با پیام‌های هشدار هدایت‌کننده.

## 🚀 راهنمای نصب و راه‌اندازی (Getting Started)

### پیش‌نیازها
- نصب بودن **Node.js** (نسخه `18.18` یا بالاتر - پیشنهاد می‌شود `20.x` یا `22.x`)
- یکی از پکیج منیجرهای `npm`، `pnpm` یا `yarn`

### ۱. کلون کردن ریپازیتوری
```bash
git clone https://github.com/alireza-hedayati/CRM-Customer-Relationship-Management-.git
cd CRM-Customer-Relationship-Management-
```

### ۲. نصب پکیج‌ها و وابستگی‌ها
```bash
npm install
# یا
pnpm install
# یا
yarn install
```

### ۳. اجرای محیط توسعه (Development Mode)
```bash
npm run dev
```
سپس مرورگر خود را باز کرده و به آدرس زیر مراجعه فرمایید:
```
http://localhost:3000
```

### ۴. ساخت بیلد نهایی برای پروداکشن (Production Build)
```bash
npm run build
npm run start
```

## 📜 اسکریپت‌های موجود (Available Scripts)

- `npm run dev`: اجرای سرور توسعه با فعال بودن Fast Refresh و Turbopack.
- `npm run build`: ایجاد بیلد بهینه‌سازی شده برای استقرار در پروداکشن.
- `npm run start`: راه‌اندازی سرور پروداکشن بر روی بیلد تولید شده.
- `npm run lint`: بررسی استانداردها و خطاهای احتمالی با ESLint.
